# UIUX_improve

[繁體中文](#繁體中文) · [English](#english)

## 繁體中文

**UIUX_improve** 是一個仍在規劃與驗證中的開源 Skill 專案，目標是協助 AI 在資料視覺化、Dashboard 資訊架構及介面審查時，先確認資料與任務，再決定呈現方式。這不是圖表套件、BI 平台或已驗證的設計系統。

### 專案方向

- **資料視覺化分析**（`data-viz-analysis`）：確認資料、指標口徑與結論是否相符；選擇圖、表或文字。
- **Dashboard 架構**（`dashboard-architecture`）：依使用者決策安排摘要、證據、明細和下一步。
- **UI/UX 探索**（`uiux-exploration`）：比較不同的資訊與互動方案，而非只替換配色。
- **設計審查**（`design-review`）：檢查可讀性、資料限制、手機版及關鍵操作。

**資料清洗、跨來源對齊、二次彙整與衍生指標計算**目前尚未實作為獨立 Skill；正評估是否新增。不能把這些能力當作現有功能。

### 使用狀態

目前是**初期草案，尚未發布或驗證**。本機已有四份 Skill 草稿，但請以 GitHub 實際可見的檔案為準；在文件與案例正式上傳並完成測試前，不宣稱支援特定代理平台或改善成效。真實營運資料可以用於本機驗證，但不應直接複製進公開範例；示範數字必須標示是否為合成資料。

尚未選定授權條款；在授權明確前，請勿假設本專案已授權再利用。

## English

**UIUX_improve** is an open-source skill project in its planning and validation stage. It aims to help AI agents check the evidence and user task before choosing visualizations, dashboard structure, or interface changes. It is not a charting library, BI platform, or validated design system.

### Planned skill areas

- **Data visualization analysis** (`data-viz-analysis`): assess metric definitions, evidence, claims, and the appropriate representation.
- **Dashboard architecture** (`dashboard-architecture`): organize summary, evidence, detail, and next steps around user decisions.
- **UI/UX exploration** (`uiux-exploration`): compare information and interaction approaches, not just visual themes.
- **Design review** (`design-review`): review readability, data limitations, mobile use, and critical interactions.

**Data cleaning, cross-source alignment, secondary aggregation, and derived-metric computation** are not yet implemented as a separate skill; that addition is under consideration. Do not treat them as current capabilities.

### Status and data policy

This is an **early draft, not a released or validated skill pack**. Four draft skill files exist locally, but the files visible on GitHub are the source of truth for what has actually been published. Platform compatibility and user outcomes have not been verified. Real operational data may be used for local validation, but must not be copied into public examples without an explicit disclosure decision; synthetic values must be labeled.

No license has been chosen yet. Do not assume reuse permissions until one is added.
